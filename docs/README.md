# Resume

## Building with PowerShell

To build the resume PDF using the PowerShell script, you may need to set the execution policy for the current process:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process
```

## Updating LinkedIn Resume

You can change your uploaded resume on LinkedIn via this link:
[https://linkedin.com/jobs/application-settings/](https://linkedin.com/jobs/application-settings/)
